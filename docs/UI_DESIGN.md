# Wedo Glass UI 设计规范

状态：MVP 方向已由产品方确认，等待实现。

## 1. 设计定位

wedo 采用明亮、通透、年轻化的液态玻璃语言。默认强调色为蓝色，玻璃强度为平衡档。设计学习苹果产品中内容优先、材质分层、连续动画和直接操控的思路，但不复制苹果图标、字体、资源或界面比例；交互必须保留 Android 返回手势、系统窗口 Insets、字体缩放、触控尺寸和无障碍语义。

关键词：清透、轻盈、可靠、校园感、克制的活力。

首版视觉参考以已确认的浅色、深色首页概念图为准，但概念图只定义观感和信息层级，不作为逐像素实现承诺。

## 2. 首页信息架构

首页直接显示完整周视图，不设置独立“今日课程”页面或模块。

- 顶部只显示“第 X 周”和今日日期，左右箭头切换周次。
- 点击周次打开周选择器；左右箭头与横向滑动负责切周，不额外占用课表空间显示“回到本周”按钮。
- 顶部大标题随纵向滚动收起为紧凑玻璃栏；星期和日期行保持吸顶。
- 左右拖动课表跟手切周，松手后用弹簧动画吸附到上一周、当前周或下一周。
- 纵向滚动查看后续节次；默认平衡密度约在一屏显示第 1–8 节，晚课继续向下查看。
- 星期范围由用户统一选择周一至周五、周一至周六或周一至周日；默认周一至周日，不使用日期列横向滚动。
- 非当前周课程默认不显示，设置中可启用淡化占位。

## 3. 浅色与深色视觉

### 3.1 浅色

- 背景：`#F7FAFF` 到 `#EAF3FF` 的冷白雾蓝渐变，叠加低对比环境光晕。
- 强调色：Wedo Blue，基准色 `#2F7DFF`。
- 主文字：深海军蓝，基准色 `#14213D`；辅助文字降低不透明度但保持对比度。
- 玻璃：半透明冷白/冰蓝、1dp 内高光、低对比外描边和柔和环境阴影。

### 3.2 深色

- 背景：深海军蓝渐变，建议从 `#071426` 到 `#0D2340`，不使用纯黑。
- 玻璃：半透明烟蓝，使用冷白/蓝色高光边缘和克制的内部反射。
- 主文字：接近白色，基准色 `#F4F7FF`；辅助文字建议 `#AFC2DF`。
- 强调色继续使用亮蓝；课程色自动调整亮度和文字颜色，不把浅色主题简单反相。

主题提供“跟随系统 / 浅色 / 深色”，默认跟随系统。

## 4. 课程卡片

- 同一课程使用稳定业务键映射固定颜色，不因重启或重复导入而变化。
- 课程色板包含天蓝、蓝紫、薄荷、珊瑚、暖黄和淡紫等可区分色；自动计算前景文字颜色。
- 卡片以有色半透明层为主，只使用轻微高光和层次，不做影响文字的强模糊。
- 全部课程共用一套信息模板。用户以复选框统一决定显示课程名、教室、教师、周次、节次或备注；MVP 默认课程名、教室、教师。
- 单击打开玻璃课程详情 Sheet；长按打开编辑、改色、复制和删除操作。
- 不在课表格内直接拖动课程，避免误改日期或节次。
- 课程冲突默认保留错位堆叠，卡片维持各自课程色，同时增加珊瑚红边框/光晕、感叹号和冲突数量；不能把整张卡统一染红。
- 原 Debug 版已有的错位堆叠、折角和侧边轨道冲突样式保留为设置选项。

## 5. 玻璃层级与设备降级

- L0 内容层：网格、文字和时间轴，保持清晰且低透明。
- L1 彩色内容层：课程卡和设置分组，轻玻璃、强可读性。
- L2 浮动玻璃层：顶部栏、星期选择透镜、Dock 和底部 Sheet。
- L3 聚焦层：确认框与危险操作，压暗背景并保持明确边界。

MVP 先用 Compose 可稳定实现的渐变、半透明、描边、高光和阴影建立统一玻璃材质。Android 13 及以上可增加受控的 AGSL 高光/折射增强；Android 8–12 使用轻量分层玻璃。增强效果不得改变尺寸、点击区域或信息层级。

外观设置提供“流畅 / 平衡 / 精致”三档，默认平衡；低性能设备自动降级，用户选择不应导致界面不可读。

## 6. 悬浮 Dock

Dock 固定为三个操作区域：

1. 左侧“课表”，返回首页并表示当前选中状态。
2. 中间突出蓝色加号，打开通用“添加课表”底部 Sheet。
3. 右侧“设置”，进入分组设置页。

交互规则：

- Dock 位于系统导航区域上方，页面内容可延伸到其后，但滚动末端必须完整露出。
- 向下滚动时 Dock 弹性下沉并隐藏；向上滚动立即出现；回到页面顶部时始终显示。
- 停止滚动本身不触发重新出现。
- 中间加号独立抬高，按下有轻微缩放，松手回弹。
- 动画必须可中断并追随用户最新手势，不排队播放。

## 7. 添加课表

中间加号打开通用添加入口，不能写成“JLJU 导入”。MVP 顺序为：

1. 教务系统导入：先进入学校选择器，当前已适配吉林建筑大学，后续可扩展其他学校。
2. WakeUp 兼容 JSON / 分享文本导入。
3. 文件导入：复用现有 ICS、CSV、HTML 和 wedo/Sleepy 原生文本能力。
4. 粘贴文本。
5. 手动创建课表或添加课程。

若当前课表关联了学校来源，Sheet 顶部可提供“同步当前课表”，学校名作为辅助信息。刷新失败不能删除最后一次成功数据。

## 8. 设置分组

复用 Debug 版已有功能并重新分组，不重写稳定业务逻辑：

- 外观：主题、强调色、玻璃质量、减少动态效果、震动。
- 课表显示：密度三档、显示星期、课程字段模板、非本周课程、课程色和冲突样式。
- 课表管理：当前课表、全部课表、编辑学期、导入、导出和清除数据。
- 隐私与关于：退出教务登录、隐私说明、开源许可、版本和诊断信息。

自定义照片背景不进入 UI MVP，留给后续版本。

## 9. 动效与触觉

- 默认“灵动但克制”：切周跟手回弹、Dock 弹性显隐、课程卡按压缩放、Sheet 连续过渡。
- 只在切周吸附、长按菜单和导入成功等关键节点提供轻触震动。
- 系统或应用启用“减少动态效果”时，弹簧位移退化为短时淡入/淡出。
- 应用设置中允许独立关闭动效和震动。

## 10. 可读性与验收

- 课程卡文字对比度自动计算；色彩个性化不能压过课程信息。
- 常用点击目标至少 48dp；屏幕阅读器可读出周次、日期、课程和冲突状态。
- 支持系统字体缩放；极端字号下允许课程副信息裁剪，但课程名、日期和导航不可消失。
- Android 8、Android 12、Android 13+ 各验证至少一个环境。
- 浅色、深色、密集课表、课程冲突、空课表、离线缓存和导入失败均需截图与交互验收。
