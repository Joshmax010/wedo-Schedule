# wedo课程表实施基线

## 产品目标

wedo课程表是面向吉林建筑大学学生的 Android 原生、本地优先课程表应用。首版支持 Android 8.0（API 26）及以上，使用学校官方网页完成登录，在本地解析和保存个人课表，不提供云同步、广告、用户中心或自建后端。

## 已锁定决策

- 基座：Sleepy，固定上游提交 `08a1f26a5d7b1a117e2216d92804b202ddde228d`。
- 上游地址：https://github.com/lingion/sleepy
- 显示名：`wedo课程表`。
- Application ID：`com.wedo.schedule`；Kotlin namespace 暂时保留上游值，避免与 JLJU 适配无关的大规模改包。
- 最低系统：Android 8.0 / API 26。
- 认证：只允许用户在官方 WebView 页面内自行输入凭据；应用不得读取或保存密码。
- 数据：课程与学期配置仅保存在设备本地；不保存原始教务响应。
- 发布：GitHub 源码与 Release APK；正式分发继续遵守 GPL-3.0。
- 运营：维护者不收费、不加广告、不经营用户数据，但不增加与 GPL 冲突的“禁止商业使用”限制。

## 阶段门

1. M1：基座调研、架构和许可证审查完成。
2. M2：品牌与安全基线完成，项目可复现构建，原有测试通过。
3. M3：用户本地确认 JLJU 官方入口、登录链路、学期请求和课表响应，并提交完全脱敏的样本。
4. M4：JLJU 离线解析器和夹具测试完成。
5. M5：官方登录、学期选择、导入、预览和本地保存端到端完成。
6. M6：周视图、课程详情、深色模式、离线缓存及错误提示验收。
7. M7：三名测试者本地真机验证与发布安全审查完成。
8. M8：发布 `1.0.0`。

M3 之前不得猜测接口或编写伪造的 JLJU 网络实现。任何证书错误、验证码和访问控制都必须交给官方认证流程处理，不得绕过。

## 首版边界

首版保留基座成熟的课程数据、周视图、详情、手动编辑和本地导入能力。桌面组件、课程提醒、云同步和多学校扩展不作为 wedo 首版功能；基座相关代码可以暂时保留以降低分叉风险，但不得在 wedo 首版导航、权限或后台行为中启用。
