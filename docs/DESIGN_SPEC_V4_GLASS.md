# wedo 界面设计规范 v4 —— 液态玻璃版

> 状态：**已落地**（P0–P6 完成，2026-10-28）。
> 本文件取代 `DESIGN_SPEC_V2.md` 的材质章节；v2 的色彩 / 字阶 / 间距 / 圆角 / 无障碍章节继续有效。
> 材质相关条目的唯一权威来源另见 `docs/glass/00_MASTER.md`（推导过程与全部 M/V/O/Q 编号）。

---

## 0. 这一版改了什么

v2 的界面基调（苹果 HIG 对齐、克制的实色卡片）**不变**。v4 只解决一件事：

> 让「液态玻璃」成为**可验证的工程能力**，而不是一次性的视觉模仿。

三条落地主线：

| 主线 | 结论 | 落地位置 |
|---|---|---|
| 分级 | 内容卡恒 G0（镀层），只有浮层允许 G1 / G2（采样） | `ui/glass/GlassQuota.kt` |
| 采样 | 用 `GraphicsLayer` 实时录制，不用 `toImageBitmap` | `ui/glass/GlassCapture.kt` |
| 运动 | 弹簧收敛成族表，减动效有统一门控 | `ui/motion/` |

## 1. 三级材质：G0 / G1 / G2

| 档 | 含义 | 采样 | 用在哪 |
|---|---|---|---|
| **G0** | 镀层。只画面层 / rim / hairline / 内高光，不采样 | ❌ | 全部内容卡、设置卡、课程块、15 个对话框 |
| **G1** | 静态 Bake。面板打开时录一次，移动期不重拍 | ✅ | 课程详情 Sheet、分享 Sheet、课程动作 Sheet、周次选择器 |
| **G2** | 实时 LiveStrip。滚动期间每帧重录 | ✅ | 底部浮动胶囊 |

**不可协商的边界**：

- 内容卡（CONTENT）**永远 G0**。内容卡要采样会让「到处半透明」导致可读性崩。
- 对话框（15 处）**永远 G0**。跨窗口 + 无预兆 → 必然一次可见材质跳变，而跳变比不做玻璃更糟。
- 底栏与顶栏**不得同时 G2**。顶栏当前判 G0，冲突自动消解。

---

## 2. 采样管线

```
WedoGlassHost          录制主内容区（不含 overlay）
  └ GlassStage         持有 GraphicsLayer + 配额计数 + Bake/LiveStrip 状态
      └ GlassBackdrop  面板消费：把舞台层搬进自己的包围盒，叠 tint / rim / hairline
```

- **只有存在采样消费者时才录制**（O-03）。全 G0 页面零离屏开销。
- **静止 = Bake**：只在内容失效时重录一次。
- **滚动 = LiveStrip**：G2 面板在滚动期间每帧重录，滚动结束 120ms 后回 Bake。
- **深度 ≤ 2**：第三层 Host 静默降 G0，不抛异常。

### 配额三道闸

| 闸 | 规则 |
|---|---|
| 语义 | BASE / CONTENT 恒 G0 |
| 数量 | G2 ≤ 3、G1 ≤ 2（同屏总量 ≤ 5，留 1 个过渡余量） |
| 面积 | 单个包围盒 ≤ 屏面积 15%；冲突时按面积倒序，大面板优先 |

超配额一律**静默降 G0**，不抛异常、不闪退。

## 3. 材质配方（G0）

| 项 | 浅色 | 深色 | 说明 |
|---|---|---|---|
| 卡片面层 alpha | 0.94 | 0.96 | Balanced 档；Smooth 0.97，Fine 0.80/0.82 |
| rim alpha | 0.30 | 0.12 | 深色下必须压住，否则一圈发亮 |
| hairline alpha | 0.065 | 0 | 与 rim 分开绘制 |
| 顶部内高光 | 0.72 | 0 | 深色下不画顶部线 |
| 圆角 | 连续曲率近似 | 同 | 卡片 / 面板 / 课程块分档 |

`Smooth`（低端机强制）无投影、无内高光；`Balanced` 双层渐变；`Fine` 加强描边与投影。

## 4. 底栏（G2 灰度）

- 形态：**悬浮胶囊**，左右留白 14dp、距系统导航栏 10dp、轻投影（浅色 4dp / 深色 8dp）。
- 交互：上滑隐藏、下滑回来（`AnimatedVisibility` 滑出后整体撤出组合，不留空白）。
- 材质：**方案 B · 干净克制**（2026-10-28 定稿，用户选定）。

### 4.1 三档透明度的分配

| 表面 | tint（浅 / 深） | blur | vibrancy | 边缘 |
|---|---|---|---|---|
| 底栏（通） | 0.52 / 0.70 | 25 | 0.18 | 0.5dp 细暗描边 |
| G1 面板（半透） | 0.78 / 0.82 | 25 | 0.40 | 0.5dp 细暗描边 |
| 对话框（不透） | 实心卡片 | — | — | 14pt 圆角 + 系统 scrim |

### 4.2 vibrancy 是这套方案的关键

半透明面板身后的内容自动**降饱和**——这是 iOS 的 vibrancy 行为，透过去是灰蓝而不是刺眼的纯蓝。实现用 `ColorFilter.colorMatrix`，**不需要 AGSL**。

只作用于**采样层**（面板背后那段内容），面板自己的图标与文字是兄弟节点，不受影响。

少了这一环，浅色下底栏压住蓝色图标时会出现一块刺眼蓝色色斑，读起来像 bug 而不是玻璃。

### 4.3 两条实测约束

| 约束 | 说明 |
|---|---|
| 模糊半径被夹在 25 | `RenderEffect.createBlurEffect` 单次半径上限 25，超出被夹断；链式多遍在当前设备**也不叠加**。所以「不刺眼」靠 tint + vibrancy，不靠更大半径 |
| L2 折射默认关闭 | 真机 A/B 显示 L1 与 L2 肉眼几乎无差别（底栏仅 52dp 高，差异全在 8px 边缘带内），按方案 P4 失败处理 ③「看不出差别 → 默认永久关闭，只留手动开关」执行 |

**为什么底栏是胶囊**：全宽条带是「贴边 UI」，没有物件感，液态玻璃也就无从谈起。

## 5. 运动系统

| 项 | 规则 |
|---|---|
| 弹簧 | 8 根族表（`WedoSprings`），生产代码禁止裸 `spring()` / `tween()` |
| 按压 | L1 同轴缩放 0.97 + 80ms 最小驻留，终值恒 1.0 |
| 减弱动效 | 用户开关 **且** 系统动画倍率 > 0，两者与关系 |
| 降级语义 | 位移类跳终态（S1）；出现类只淡变（S3）；材质不降级（M-39） |
| 中断 | 用 `animateTo` 重设目标继承速度，禁止 `stop()` 后再 `animateTo` |

## 6. 对话框

全 app 唯一入口 `WedoDialog`：

- 15 处 `AlertDialog` 全部经该包装，业务文件不得直接调用 `AlertDialog`。
- 统一：白卡片底（深色 `#1C1C1E`）、14pt 圆角、`tonalElevation = 0.dp`。
- 材质恒 G0，**完全不透**。「浮起来」靠白卡片底 + 圆角 + 系统 scrim，不靠透明。

---

## 7. 不做什么

| 不做 | 原因 |
|---|---|
| 内容卡采样 | 可读性优先，内容卡要「稳」不要「透」 |
| 对话框采样 | 跳变比不做更糟 |
| 玻璃烘焙/浮雕 3D 轮廓（L3 流体轮廓） | 本项目无相邻胶囊群场景，成本不抵收益 |
| 玻璃随减动效关闭 | 材质不是动画，关掉只会变丑不会变快 |
| 顶栏 G2 | 顶栏在正常流里，内容不上滚到它下面，无内容可采 |
