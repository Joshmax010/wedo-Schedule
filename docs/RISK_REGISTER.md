# 风险登记表

| 风险 | 级别 | 控制措施 | 阻断条件 |
|---|---|---|---|
| JLJU 系统和接口尚未确认 | 高 | 仅接受真实登录后的脱敏取证 | 无响应证据时不得实现网络适配 |
| WebView 跨域脚本桥被恶意页面调用 | 高 | 域名白名单、按需注入/移除桥、外链交系统浏览器 | 白名单测试未通过不得真号测试 |
| 证书或明文流量泄露凭据 | 高 | 不放行证书错误，HTTPS 优先，禁用全局明文 | 认证域需要绕过 TLS 时停止 |
| 课程数据进入系统云备份 | 高 | `allowBackup=false`，所有数据域默认排除 | APK manifest 未验证不得发布 |
| 真实账号或响应进入 Git | 高 | `.gitignore`、提交前扫描、只用脱敏夹具 | 检出敏感信息立即阻断并清理历史 |
| 上游复杂周次模型丢失离散周 | 中 | 将离散周拆成精确行/段并做 round-trip 测试 | 任一周次用例失败不得发布 |
| 上游更新造成分叉冲突 | 中 | 保留完整历史和 `upstream`；改动集中在品牌、安全和 JLJU 层 | 公共解析器回归时停止合并 |
| 本机构建环境缺 Android SDK 37 | 中 | 安装官方 SDK 后运行完整构建；CI 固定包版本 | 未成功构建 Debug APK 不通过 M2 |
| 学校系统改变接口 | 中 | 匿名错误分类、夹具回归、旧缓存不覆盖 | 刷新失败不得清空已导入课表 |
